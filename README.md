# Resonance

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:8015。

## 节拍网格

载入本地音频（或演示音轨）后，在「06 / BEAT GRID」面板点击「识别速度与强拍」。识别结果只作为候选列出，不会自动替换现场节拍；逐个试听后按「采用」才会生成网格。

- **候选解释**：同一段音频会给出标准速度、半速、双速以及相位 A/B 等几种读法，各自标注小节数与「待确认」小节数，避免弱鼓点被悄悄当成强拍。
- **波形校准**：在波形上拖动竖直的强拍线可修正强拍位置；单击空白处定位播放头；拖动标尺顶部的三角形可设置循环起止点。左右方向键逐小节移动，「−/+10ms」微调，「整体 ±10ms」平移整份网格。
- **不确定区段**：「不确定区段」列出所有低置信度小节，可整段试听、跳到该段逐小节修正，或整段确认；「保留不确定」会把小节保持在待确认状态，不会被自动抹平。
- **中途变速**：检测按小段估计速度并分段追随节拍，小节之间的间距会随音乐改变；读数取相邻小节的中位数，因此不会在真实变速前抖动。
- **循环**：循环点默认对齐所选小节的边界。小节编号取自网格本身，因此跨小节循环回到起点时编号仍然连续；跳转、暂停恢复和循环回卷都不会重播已经走过的拍，也不会重复触发已经执行过的场景。
- **场景触发**：确认网格后，场景切换排队到下一个强拍执行；面板会提示「将在下一强拍进入」，也可以取消。没有网格或手动敲击接管时立即切换。
- **手动敲击**：T 键或 TAP 按钮临时接管速度显示与节拍闪光，原网格保持不变；数秒无敲击后自动交还，交还时以当前播放位置重新对齐，不会连闪多个节拍，也不会让录制中的节拍标记倒序。
- **录制事件**：录制期间每次强拍/拍点与场景切换都会记入当前 take，保存后在小节泳道上按顺序显示。标记使用录制自身的时钟并强制单调，因此循环与跳转不会产生倒序标记。
